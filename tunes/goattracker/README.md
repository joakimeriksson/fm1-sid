# GoatTracker 2's example songs

The songs GoatTracker 2 ships with (its distribution, under the GNU GPL version 2: its `copying`), as
their composers made them. FM-1 SID's own firmware carries them as its tunes (`dock/build_solo.sh`),
Dojo first.

| Song | Composer |
| --- | --- |
| Dojo (`dojo.sng`) | Cadaver (Lasse Öörni), Covert Bitops 2002 |
| Unleash The F****** Fury (`unleash.sng`) | Cadaver, Covert Bitops 2004 |
| On A Sanction From CIA (`sanction.sng`) | Cadaver, Covert Bitops 2005 |
| The Consultant (`consultant.sng`) | Cadaver, Covert Bitops 2002 |
| Transylvanian Whipping (`transylvanian.sng`) | Cadaver, Covert Bitops 2005 |
| My Own Hyperspace (`hyperspace.sng`) | Jammer |
| Sixpack Of Cola (`sixpack.sng`) | No-XS, after an original song by beek |
| GhostTrackers (`ghosttrackers.sng`) | Hein |
| Everlasting Annoyance (`everlasting.sng`) | Richard Bayliss, The New Dimension |
| I'll Be A Pimp In Cabrini Green (`cabrinigreen.sng`) | Randall |

The composers' names as GoatTracker's `examples/goatcompo.txt` and the songs themselves give them.
